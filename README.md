# modulo3_Final_USIP
## Planificación con Issues

El proyecto fue organizado mediante Issues para dividir el desarrollo del sistema de cobradores en tareas claras:

### Issue 1: Registro y gestión de deudores

Implementar el módulo para registrar deudores, incluyendo datos personales, teléfonos, referencias familiares y observaciones del cobrador.

---

### Issue 2: Importación de cartera desde Excel

Desarrollar la funcionalidad que permita al gerente subir el archivo Excel del banco y distribuir automáticamente los clientes a cada cobrador.

---

### Issue 3: Geolocalización de clientes

Crear el sistema de registro de ubicación (latitud y longitud) para cada deudor y visualizarla en el mapa, facilitando el trabajo de campo del cobrador.
